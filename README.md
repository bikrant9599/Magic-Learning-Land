# Magic Learning Land

Magic Learning Land is an educational gaming platform for children from Nursery to Class 5. The purpose of the platform is to make learning more enjoyable by combining school subjects with interactive games, challenges, stories, puzzles, and activities.

The platform should be simple enough for young children to use while also providing useful learning progress information for parents and teachers.

The main idea is:

Play, Learn, Practice, Improve, Progress.

---

## Project Goals

Magic Learning Land should help children learn through interactive activities instead of relying only on traditional quizzes and worksheets.

The platform covers:

- English
- Mathematics
- Science
- Environmental Studies
- General Knowledge
- Reading
- Vocabulary
- Grammar
- Logical Reasoning
- Problem Solving
- Geography
- Basic Computer and Everyday Knowledge

The difficulty should increase naturally as the student moves from Nursery to Class 5.

The games should not simply become harder by increasing numbers. New concepts, longer questions, more complex reasoning, and more advanced problem solving should be introduced at higher levels.

# Classes and Levels

The platform supports the following classes:

| Level | Class | Main Learning Areas |
|---|---|---|
| Level 1 | Nursery | Colors, shapes, sounds, counting, basic vocabulary |
| Level 2 | LKG | ABC, phonics, numbers, objects, patterns |
| Level 3 | UKG | Reading readiness, words, addition, subtraction |
| Level 4 | Class 1 | English, Maths, EVS, logic, time, money |
| Level 5 | Class 2 | Multiplication, division, grammar, science |
| Level 6 | Class 3 | Fractions, comprehension, science, geography |
| Level 7 | Class 4 | Decimals, geometry, grammar, reasoning |
| Level 8 | Class 5 | Advanced maths, English, science, geography, logic |

The initial target is 20 educational games for every class.

That gives:

8 classes × 20 games = 160 games.

The architecture should make it easy to add more games later without rewriting the application.

# Onboarding System

When a new user opens the website for the first time, the application should provide a simple onboarding process.

## Step 1: Welcome

Show:

"Welcome to Magic Learning Land"

Button:

"Let's Play"

After pressing the button, smoothly move to the class selection screen.

## Step 2: Select Class

Ask:

"What is your class?"

Show:

- Nursery
- LKG
- UKG
- Class 1
- Class 2
- Class 3
- Class 4
- Class 5

The selected class determines which games and learning content the student receives.

## Step 3: Enter Name

Ask:

"What is your name?"

Allow the child to enter their first name or nickname.

Do not request unnecessary personal information.

## Step 4: Personalized Welcome

After the child enters their name, show:

"Welcome, [Name]!"

Then:

"Your Class [X] learning adventure is ready."

Button:

"Start My Adventure"

The student should then be taken directly to their selected class world.

---

# Returning Users

The application must recognize returning users.

If the user has already completed onboarding, do not ask for their class and name again.

Instead show:

"Welcome back, [Name]!"

Then show:

"Continue Adventure"

The user should be taken directly to their saved class.

If possible, also remember the last world and last game they were playing.

---

# Persistent User Data

User progress is extremely important.

The application must never delete, reset or overwrite existing progress simply because the browser was refreshed, closed, reopened or the application was updated.

Save and restore:

- Name
- Selected class
- Current level
- Completed games
- Game scores
- Best scores
- Stars
- Coins
- Badges
- Trophies
- Daily challenge progress
- Learning streak
- Subject progress
- Accuracy
- Unlocked worlds
- Unlocked characters
- Last played game
- Sound preferences
- Music preferences
- Other existing game settings

The expected experience is:

Play → Save → Leave → Return → Continue

The student should never have to start from the beginning because they closed the website.
